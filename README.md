# KPuzzle

Classic logic puzzles in one app — **Akari, Battleships, Fillomino,
Hashiwokakero, Hitori, Kakurasu, Kakuro, Masyu, Minesweeper, Mosaic,
Nonograms, Number Paths, Nurikabe, Shikaku, Slitherlink, Star Battle,
Sudoku, Suguru, Takuzu, and Tents** — built with
Kotlin Multiplatform and Compose, running on Android, iOS, desktop, and the
web.

**Play in the browser:** https://kanphis.github.io/KPuzzle/

The web version is a PWA: install it from the browser menu and it runs
fully offline — puzzles are generated on your device, and every game has
step-by-step hints.

## About this repository

This repository hosts the **prebuilt web bundle only** and is updated whenever a new production build is published. The application source code is private.

The third-party open-source libraries used by the app are listed with their full license texts in the app itself, under **Settings → More → Open-source licenses**.

## Privacy

The app collects no data and works fully offline — see the [privacy policy](privacy.html).
